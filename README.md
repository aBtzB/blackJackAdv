# blackJack

A small blackjack game for two people sharing a screen. Pick your bets, take turns hitting or standing, and see who keeps their chips.

Made as a hobby project with plain **HTML, CSS and JavaScript**. No frameworks, package installation or build process.

## Play

On a computer:

1. Download and extract the ZIP.
2. Open the `blackJack` folder.
3. Double-click **index.html** to open it in your browser.

All game files are included, so it can run offline. For playing on a phone, publish the files on GitHub Pages and open the website link.
